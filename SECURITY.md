# Security

## Reporting a vulnerability

If you believe you have found a security issue, please report it privately so it can be addressed before public disclosure.

**Preferred:** Use [GitHub private vulnerability reporting](https://github.com/dazuaz/git-smart-commits/security/advisories/new) if it is enabled on the repository.

**Alternative:** Open a draft security advisory or contact the maintainers through a private channel (for example, email listed on their GitHub profile) with enough detail to reproduce the issue.

Please allow reasonable time for a fix before discussing the issue in public forums.
